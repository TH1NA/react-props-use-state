# React Props and State

A small React app that demonstrates passing props to reusable components and
updating component state with `useState`.

## Run locally

```sh
npm install
npm run dev
```

## Examples

- Course cards receive their title and description through props.
- Product cards receive product details through props and track cart quantity
  with `useState`.
- The counter uses `useState` to increment and reset its value.

Run `npm run lint` and `npm run build` to check the project.
